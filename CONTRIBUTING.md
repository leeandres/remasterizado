# Contribuir a MasterAI Pro

Gracias por tu interés. Para contribuir:

1. Haz fork del repositorio.
2. Crea una rama: `git checkout -b feature/mi-mejora`.
3. Instala dependencias: `npm install`.
4. Ejecuta `npm run typecheck` y `npm run build` antes de enviar.
5. Abre un Pull Request describiendo los cambios.

## Estilo de código
- TypeScript estricto.
- Componentes React con Tailwind.
- Mantén la UI en español y el tema oscuro.

## Reportar bugs
Usa la plantilla de issue "Bug report" con pasos para reproducir y navegador/versión.
